# Client sector photos

Real photographs of named clients on the `/clients` page, used only where
a free-to-reuse photo of that *exact* building could be confirmed. Everywhere
else on that page kept its earlier stock photo rather than risk showing the
wrong building under a real client's name.

All from [Wikimedia Commons](https://commons.wikimedia.org), licensed
CC BY-SA (reuse requires attribution — keep this file, or add on-page
credit if you want it more visible). Resized to 900px wide, WebP.
